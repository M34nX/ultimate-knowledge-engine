# مبانی و راهبری

**شناسه حوزه:** 00  
**وضعیت:** برنامه‌ریزی‌شده

این حوزه نحوه استفاده از دانشنامه و روش‌های مؤثر یادگیری موضوعات فنی را توضیح می‌دهد.

## موضوعات

- راهبری در UKE و درک وضعیت انتشار محتوا.
- روش‌های یادگیری، تمرین هدفمند و خودارزیابی.
- پیش‌نیازها، اهداف آموزشی و نقشه مهارت‌ها.
- مطالعه فنی، سواد مستندسازی و ارزیابی منابع.
- Git، روند مشارکت و استانداردهای پروژه.
- استفاده مسئولانه از ابزارهای هوش مصنوعی در یادگیری.
