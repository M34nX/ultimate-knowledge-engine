# دواپس و رایانش ابری

**شناسه حوزه:** 07  
**وضعیت:** برنامه‌ریزی‌شده

این حوزه تحویل مطمئن نرم‌افزار و بهره‌برداری از برنامه‌ها و زیرساخت‌ها را پوشش می‌دهد.

## نقشه موضوعات

- کنترل نسخه و گردش‌کار همکاری.
- سیستم‌های ساخت و یکپارچه‌سازی مداوم.
- تحویل مداوم و راهبردهای استقرار.
- کانتینرها و مفاهیم ارکستریشن.
- زیرساخت به‌عنوان کد و مدیریت پیکربندی.
- مبانی رایانش ابری و مدل‌های سرویس.
- پایش، گزارش‌ها، رهگیری و مشاهده‌پذیری.
- مهندسی قابلیت اطمینان، پشتیبان‌گیری و بازیابی بحران.
- مدیریت هزینه و بهره‌برداری پایدار.

## استاندارد آموزش

مثال‌ها باید در محیط‌های غیرتولیدی و امن اجرا شوند. پیش از راهنمایی عملیاتی، مجوزها، هزینه‌ها، بازیابی از خطا و پیامدهای امنیتی را توضیح دهید.
