# دورهٔ مبانی توسعهٔ وب

**وضعیت:** پیش‌نویس آموزشی

این دوره مسیر پایهٔ توسعهٔ وب را از مدل درخواست/پاسخ آغاز می‌کند و به HTML معنایی، دسترس‌پذیری، CSS واکنش‌گرا و JavaScript تعاملی می‌رسد.

## مهارت‌های مورد انتظار

- توضیح نقش مرورگر، سرور و HTTP؛
- ساخت صفحهٔ HTML معنایی و قابل پیمایش با صفحه‌کلید؛
- طراحی چیدمان سازگار با اندازه‌های مختلف صفحه؛
- نوشتن منطق پایه با JavaScript؛
- تعامل با DOM و دریافت دادهٔ JSON؛
- مدیریت وضعیت پاسخ ناموفق و خطای شبکه.
