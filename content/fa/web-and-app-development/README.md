# توسعه وب و اپلیکیشن

**شناسه حوزه:** 04  
**وضعیت:** مسیر مقدماتی در Draft

این حوزه فناوری‌ها و روش‌های مهندسی مورد استفاده برای ساخت برنامه‌های وب، موبایل و کلاینت را پوشش می‌دهد.

## مسیر آموزشی موجود

- [دورهٔ مبانی توسعهٔ وب — ۵ درس](web-foundations/README.md)

## نقشه موضوعات

- HTML، CSS، پلتفرم مرورگر و دسترس‌پذیری.
- JavaScript، TypeScript و معماری Frontend.
- سرویس‌های Backend، API، مفاهیم احراز هویت و یکپارچه‌سازی.
- HTTP، URL، مرورگر، رندرینگ و کارایی وب.
- توسعه موبایل برای پلتفرم‌های اصلی.
- مدیریت وضعیت، تست و ابزارهای ساخت.
- مهندسی تجربه کاربری و بین‌المللی‌سازی.
- استقرار و مبانی امنیت برنامه.

## استاندارد آموزش

استانداردهای وب را از رفتار اختصاصی مرورگر، قراردادهای Framework و قابلیت‌های شرکت‌های میزبانی تفکیک کنید. در موضوعات مرتبط، دسترس‌پذیری و امنیت را نیز بررسی کنید.
