# محتوای فارسی

فارسی یکی از زبان‌های اصلی و درجه‌اول این پروژه است. ساختار محتوا باید با نسخه انگلیسی هماهنگ باشد، اما ترجمه نباید به ترجمه واژه‌به‌واژه محدود شود.

## ساختار

برای هر مفهوم از شناسه پایدار مشترک استفاده می‌شود. عنوان و متن می‌توانند میان زبان‌ها متفاوت باشند، اما هویت آموزشی محتوا ثابت می‌ماند.

## وضعیت انتشار

وجود فایل به معنای کامل یا تأییدشدن آن نیست. مطالب پیش‌نویس باید تا پایان بازبینی و بررسی فنی با وضعیت Draft باقی بمانند.
