# مهندسی نرم‌افزار

**شناسه حوزه:** 03  
**وضعیت:** برنامه‌ریزی‌شده

مهندسی نرم‌افزار فرایند اصولی مشخص‌کردن نیازها، طراحی، ساخت، آزمون، استقرار و نگهداری سیستم‌های نرم‌افزاری را پوشش می‌دهد.

## نقشه موضوعات

- نیازمندی‌ها، User Story و معیارهای پذیرش.
- اصول طراحی، ماژولار بودن، انسجام و وابستگی.
- سبک‌های معماری و ثبت تصمیم‌های معماری.
- الگوهای طراحی و بازآرایی کد.
- راهبردهای تست و تضمین کیفیت.
- قابلیت اطمینان، مشاهده‌پذیری و نگهداری‌پذیری.
- بازبینی کد، کنترل نسخه و همکاری تیمی.
- بدهی فنی، مستندسازی و چرخه عمر نرم‌افزار.

## استاندارد آموزش

به‌جای قوانین مطلق، مصالحه‌ها و شرایط استفاده را توضیح دهید. هدف یک الگو را از پیاده‌سازی خاص آن جدا کنید.
