# پایگاه‌های داده

**شناسه حوزه:** 09  
**وضعیت:** برنامه‌ریزی‌شده

این حوزه نظریه و مهندسی سیستم‌های ذخیره‌سازی پایدار داده را پوشش می‌دهد.

## نقشه موضوعات

- مدل‌سازی داده، موجودیت‌ها، روابط و محدودیت‌ها.
- جبر رابطه‌ای و مفاهیم پایگاه داده رابطه‌ای.
- پرس‌وجوهای SQL، پیوند، تجمیع و توابع پنجره‌ای.
- تراکنش‌ها، سطوح جداسازی، سازگاری و کنترل هم‌زمانی.
- ایندکس، برنامه‌ریزی پرس‌وجو و تحلیل کارایی.
- سیستم‌های سندی، کلید-مقدار، گرافی، ستونی و سری زمانی.
- تکثیر، افراز، پشتیبان‌گیری و بازیابی.
- یکپارچگی داده، مهاجرت و امنیت عملیاتی.

## استاندارد آموزش

قابلیت‌های استاندارد SQL را از افزونه‌های اختصاصی هر محصول تفکیک کنید. در تفاوت‌های رفتاری، موتور و نسخه پایگاه داده را مشخص کنید. مصالحه میان صحت و کارایی نیز توضیح داده شود.
