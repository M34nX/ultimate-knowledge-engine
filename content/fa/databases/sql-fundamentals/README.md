# دورهٔ مبانی پایگاه داده و SQL با PostgreSQL

**وضعیت:** پیش‌نویس آموزشی

این مسیر از مدل‌سازی رابطه‌ای آغاز می‌شود و به queryهای SQL، تجمیع، اتصال جدول‌ها، تراکنش‌ها و بررسی کارایی می‌رسد. مثال‌ها بر PostgreSQL متمرکزند؛ تفاوت‌های موتورهای دیگر باید جداگانه بررسی شوند.

## توانایی‌های مورد انتظار

- طراحی جدول با کلید اصلی و خارجی؛
- نوشتن queryهای فیلتر، مرتب‌سازی و تجمیع؛
- اتصال رابطه‌ای جدول‌ها و تفسیر نتیجه؛
- توضیح هدف تراکنش و تفاوت commit/rollback؛
- بررسی اولیهٔ برنامهٔ اجرا و مصالحهٔ ایندکس.

## پروژهٔ پیشنهادی

یک پایگاه دادهٔ کتابخانه طراحی کنید: کتاب، نویسنده، عضو و امانت. کلیدها و محدودیت‌ها را تعیین کنید، سپس queryهایی برای جست‌وجو، گزارش امانت‌ها و شمارش کتاب‌های هر نویسنده بنویسید.

## راه‌اندازی آزمایشگاه

از یک محیط محلی و دادهٔ آزمایشی استفاده کنید. پیش از اجرای دستورهای تغییردهنده، پایگاه دادهٔ تمرینی بسازید و پشتیبان داشته باشید. نمونه‌ها برای آموزش‌اند و بدون بررسی نباید روی دادهٔ واقعی اجرا شوند.
