# مدل رابطه‌ای، جدول و کلیدها

## ۱. پایگاه دادهٔ رابطه‌ای

در مدل رابطه‌ای، داده‌ها در رابطه‌ها (که در SQL معمولاً جدول نامیده می‌شوند) سازمان‌دهی می‌شوند. هر جدول مجموعه‌ای از سطرها و ستون‌ها دارد. سطر یک رکورد و ستون یک ویژگی با نوع مشخص است.

نمونهٔ جدول دانشجو:

| student_id | name | grade |
|---:|---|---:|
| 101 | Mina | 18 |
| 102 | Arman | 16 |

## ۲. کلید اصلی

کلید اصلی (Primary key) هر سطر را به‌طور یکتا مشخص می‌کند. مقدار آن نباید تکراری یا تهی باشد. کلید اصلی می‌تواند از یک ستون یا چند ستون تشکیل شود.

```sql
CREATE TABLE students (
    student_id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    grade NUMERIC(4, 2)
);
```

قید `NOT NULL` ورود مقدار تهی را منع می‌کند. برای کنترل دامنهٔ مقدار می‌توان از قیدهایی مانند `CHECK` استفاده کرد.

## ۳. کلید خارجی

کلید خارجی (Foreign key) رابطهٔ میان دو جدول را برقرار می‌کند و یکپارچگی ارجاعی را حفظ می‌کند:

```sql
CREATE TABLE courses (
    course_id INTEGER PRIMARY KEY,
    title TEXT NOT NULL
);

CREATE TABLE enrollments (
    student_id INTEGER REFERENCES students(student_id),
    course_id INTEGER REFERENCES courses(course_id),
    PRIMARY KEY (student_id, course_id)
);
```

در این مدل، هر ثبت‌نام به دانشجو و درس موجود اشاره می‌کند. کلید اصلی مرکب مانع ثبت‌نام تکراری یک دانشجو در همان درس می‌شود.

## ۴. رابطه‌ها

- یک‌به‌یک: یک رکورد از A با حداکثر یک رکورد از B مرتبط است.
- یک‌به‌چند: یک رکورد A می‌تواند چند رکورد B داشته باشد.
- چندبه‌چند: با یک جدول واسط مانند enrollments پیاده‌سازی می‌شود.

## ۵. طراحی مناسب

دادهٔ تکراری و ناسازگار می‌تواند به مشکلات درج، به‌روزرسانی و حذف منجر شود. نرمال‌سازی با تفکیک مفهوم‌ها و تعریف رابطه‌ها به کاهش این مشکلات کمک می‌کند؛ اما طراحی باید با الگوی واقعی استفاده و نیازمندی‌های برنامه متناسب باشد.

## ۶. اشتباهات رایج

- استفاده از نام یا ایمیل به‌عنوان شناسهٔ ثابت بدون بررسی تغییرپذیری.
- فراموش‌کردن کلید خارجی در جدول واسط.
- ذخیرهٔ چند مقدار نامرتبط در یک ستون متنی.
- فرض اینکه کلید خارجی به‌تنهایی تمام قواعد کسب‌وکار را بیان می‌کند.

## ۷. تمرین

۱. برای کتاب و نویسنده، دو جدول و کلید اصلی تعریف کنید.
۲. رابطهٔ چندبه‌چند میان کتاب و نویسنده را با جدول واسط طراحی کنید.
۳. قیدی بنویسید که سال انتشار منفی نباشد.
