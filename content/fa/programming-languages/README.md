# زبان‌های برنامه‌نویسی — فارسی

هر راهنمای زبان باید پروفایل، دامنه نسخه‌ها، مسیر یادگیری، منابع، مثال‌ها، تمرین‌ها و آزمون‌های متناسب با همان زبان را داشته باشد.

ساختار فصل‌ها نباید برای تمام زبان‌ها یکسان و اجباری باشد. برای نمونه، Rust به مالکیت و قرض‌گیری، JavaScript به مدل اجرا و Event Loop و زبان C به مدیریت حافظه نیاز دارد.
