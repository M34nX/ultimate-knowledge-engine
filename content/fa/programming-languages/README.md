# زبان‌های برنامه‌نویسی — فارسی

راهنماهای اختصاصی زبان‌ها و پارادایم‌های برنامه‌نویسی را بررسی و مقایسه کنید. [دفترچه ۴۰ زبان](../../../learning/programming-languages/40-language-workbook.fa.md) نمونه‌کدهای دسته‌بندی‌شده را ارائه می‌کند.
