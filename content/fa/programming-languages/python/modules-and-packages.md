# ماژول‌ها و بسته‌ها در پایتون

## ۱. چرا کد را تقسیم می‌کنیم؟

وقتی برنامه رشد می‌کند، نگهداری همه توابع و داده‌ها در یک فایل دشوار می‌شود. ماژول امکان می‌دهد کد مرتبط را در فایلی مستقل قرار دهیم و در جای دیگر استفاده کنیم.

## ۲. واردکردن ماژول

```python
import math

print(math.sqrt(81))
```

با `import math` ماژول وارد فضای نام `math` می‌شود. راه دیگر:

```python
from math import sqrt
print(sqrt(81))
```

استفاده از `import *` معمولاً توصیه نمی‌شود، زیرا مشخص نمی‌کند نام‌ها از کجا آمده‌اند و ممکن است نام‌های موجود را بازنویسی کند.

## ۳. ساخت ماژول خودمان

دو فایل در یک پوشه بسازید:

`calculator.py`:

```python
def add(a, b):
    return a + b
```

`main.py`:

```python
import calculator

print(calculator.add(4, 5))
```

وقتی هر دو فایل در مسیر قابل دسترس مفسر باشند، فایل دوم می‌تواند تابع فایل اول را فراخوانی کند.

## ۴. نقطه ورود برنامه

در فایل اجرایی، الگوی زیر اجازه می‌دهد کد اصلی هنگام اجرای مستقیم فایل اجرا شود، نه هنگام import شدن آن:

```python
def main():
    print("Program started")

if __name__ == "__main__":
    main()
```

این الگو برای نوشتن ماژول‌های قابل استفاده مجدد بسیار مفید است.

## ۵. بسته چیست؟

بسته روشی برای سازمان‌دهی چند ماژول در یک فضای نام است. در پروژه‌های امروزی بسته‌ها معمولاً در قالب پوشه‌های منظم و مطابق قواعد import ساخته می‌شوند. فایل `__init__.py` در بسته‌های معمولی برای مشخص‌کردن و پیکربندی بسته کاربرد دارد؛ هرچند فضای نام بسته‌ها در پایتون امکانات دیگری هم دارد.

ساختار نمونه:

```text
my_app/
    __init__.py
    main.py
    calculations.py
    reports/
        __init__.py
        summary.py
```

## ۶. مسیر جست‌وجوی ماژول

پایتون ماژول‌ها را در مسیرهای مشخصی جست‌وجو می‌کند. نام‌گذاری فایل خود را با نام ماژول‌های استاندارد تداخل ندهید؛ برای نمونه فایل `random.py` در پروژه ممکن است واردکردن ماژول استاندارد `random` را مختل کند.

## ۷. اشتباهات رایج

- نام‌گذاری فایل با نام کتابخانه استاندارد.
- واردکردن همه نام‌ها با `import *`.
- اجرای کد اصلی در سطح ماژول هنگام import.
- اشتباه گرفتن پوشه پروژه با بسته نصب‌شده از مخزن بسته‌ها.

## ۸. تمرین

۱. دو تابع محاسباتی را در فایل جداگانه ذخیره و از فایل اصلی وارد کنید.
۲. تابع `main()` بسازید و آن را در شرط `__name__` فراخوانی کنید.
۳. ساختار پیشنهادی یک بسته برای مدیریت کتابخانه کتاب را طراحی کنید.
