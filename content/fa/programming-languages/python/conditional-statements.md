# تصمیم‌گیری با شرط‌ها در پایتون

## ۱. شرط چه کاری انجام می‌دهد؟

برنامه همیشه نباید همه دستورها را بدون توجه به وضعیت اجرا کند. ساختار شرطی امکان می‌دهد بر اساس درست یا نادرست بودن یک عبارت، مسیر اجرای برنامه انتخاب شود.

## ۲. ساختار if و else

```python
score = 15

if score >= 10:
    print("قبول")
else:
    print("نیاز به تلاش بیشتر")
```

ابتدا شرط بررسی می‌شود. اگر نتیجه درست باشد، بدنه `if` اجرا می‌شود؛ در غیر این صورت بدنه `else`.

## ۳. چند حالت با elif

برای بررسی چند حالت از `elif` استفاده می‌شود:

```python
score = 18

if score >= 18:
    grade = "عالی"
elif score >= 15:
    grade = "خوب"
elif score >= 10:
    grade = "قبول"
else:
    grade = "نیازمند تمرین"

print(grade)
```

شرط‌ها از بالا به پایین بررسی می‌شوند و نخستین شرط درست، مسیر اجرا را تعیین می‌کند.

## ۴. عملگرهای مقایسه و منطق

عملگرهای رایج مقایسه عبارت‌اند از `==`، `!=`، `<`، `<=`، `>` و `>=`. برای ترکیب شرط‌ها از `and`، `or` و `not` استفاده می‌شود:

```python
age = 17
has_ticket = True

if age >= 13 and has_ticket:
    print("اجازه ورود")
```

## ۵. تورفتگی اهمیت دارد

در پایتون تورفتگی بخشی از نحو زبان است و محدوده بدنه شرط را مشخص می‌کند. دستورهایی که در یک بلوک قرار دارند باید تورفتگی سازگار داشته باشند.

## ۶. اشتباهات رایج

- استفاده از `=` به‌جای `==` در عبارت مقایسه.
- نادیده‌گرفتن ترتیب شرط‌ها در زنجیره `if/elif`.
- فراموش‌کردن دونقطه پس از شرط.
- ناسازگاری تورفتگی.
- نوشتن شرط‌های پیچیده بدون شکستن آن‌ها به عبارت‌های قابل فهم.

## ۷. تمرین

۱. برنامه‌ای بنویسید که زوج یا فرد بودن یک عدد را تشخیص دهد.
۲. با سه بازه نمره، پیام مناسب چاپ کنید.
۳. شرطی بنویسید که بررسی کند عددی بین ۱۰ و ۲۰ (با احتساب دو سر بازه) قرار دارد.
