# متغیرها و مقدارها در پایتون

> وضعیت این درس: پیش‌نویس؛ مثال‌ها آموزشی‌اند و پیش از انتشار نهایی باید در محیط پایتون اجرا شوند.

## ۱. متغیر چیست؟

متغیر نامی است که به یک شیء در برنامه اشاره می‌کند. با استفاده از متغیر می‌توان یک مقدار را ذخیره و بعداً در محاسبات یا تصمیم‌گیری‌ها استفاده کرد.

```python
name = "Sara"
age = 16
temperature = 21.5
```

در این مثال، سه نام به مقدارهایی با نوع‌های متفاوت اشاره می‌کنند.

## ۲. دستور انتساب

علامت `=` در پایتون عملگر انتساب است؛ یعنی مقدار سمت راست را به نام سمت چپ نسبت می‌دهد. این علامت در این کاربرد به معنی «برابر بودن ریاضی» نیست.

```python
score = 10
score = score + 5
print(score)
```

خروجی:

```text
15
```

در خط دوم ابتدا مقدار فعلی `score` خوانده می‌شود، پنج واحد به آن افزوده می‌شود و نتیجه دوباره به همان نام نسبت داده می‌شود. شکل کوتاه‌تر آن `score += 5` است.

## ۳. قواعد نام‌گذاری

- نام می‌تواند شامل حروف، رقم و زیرخط باشد.
- نام نباید با رقم آغاز شود.
- حروف بزرگ و کوچک متفاوت‌اند؛ `score` و `Score` دو نام جدا هستند.
- واژه‌های رزروشده مانند `if` و `for` نام معتبر متغیر نیستند.
- نام‌های معنادار مانند `student_count` از نام‌های مبهم بهترند.

## ۴. مقدار و نوع

نوع یک مقدار مشخص می‌کند چه داده‌ای را نمایش می‌دهد و چه عملیاتی روی آن معنا دارد. تابع `type()` نوع شیء را نشان می‌دهد:

```python
count = 12
title = "Python"
is_ready = True

print(type(count))
print(type(title))
print(type(is_ready))
```

## ۵. اشتباهات رایج

- استفاده از `=` به‌جای `==` برای مقایسه در شرط‌ها.
- شروع نام متغیر با عدد.
- استفاده از نام‌های بسیار کوتاه و نامفهوم.
- تصور اینکه انتساب یک مقدار، نسخه‌ای مستقل از آن را همیشه کپی می‌کند؛ رفتار دقیق به نوع شیء بستگی دارد.

## ۶. تمرین

۱. سه متغیر برای نام یک کتاب، تعداد صفحه‌ها و قیمت آن تعریف کنید.
۲. مقدار یک متغیر عددی را با استفاده از `+=` افزایش دهید.
۳. با `type()` نوع سه مقدار مختلف را بررسی کنید.
