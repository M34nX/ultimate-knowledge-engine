# عملگرها و عبارت‌ها در پایتون

## هدف درس

عملگرها روی مقدارها عملیاتی انجام می‌دهند و عبارت‌ها ترکیبی از مقدارها، نام‌ها و عملگرها هستند که نتیجه تولید می‌کنند. فهم دقیق آن‌ها برای نوشتن شرط، محاسبه و پردازش داده ضروری است.

## ۱. عملگرهای ریاضی

| عملگر | معنی | نمونه |
|---|---|---|
| `+` | جمع | `7 + 2` → `9` |
| `-` | تفریق | `7 - 2` → `5` |
| `*` | ضرب | `7 * 2` → `14` |
| `/` | تقسیم معمولی | `7 / 2` → `3.5` |
| `//` | تقسیم کف | `7 // 2` → `3` |
| `%` | باقیمانده | `7 % 2` → `1` |
| `**` | توان | `2 ** 3` → `8` |

تقسیم بر صفر مجاز نیست و خطای `ZeroDivisionError` ایجاد می‌کند. تقسیم کف برای عددهای منفی نیز به سمت منفی بی‌نهایت گرد می‌شود؛ بنابراین همیشه معادل حذف بخش اعشاری نیست.

## ۲. مقایسه

عملگرهای `==`، `!=`، `<`، `<=`، `>` و `>=` نتیجه بولی تولید می‌کنند:

```python
temperature = 24
print(temperature >= 20)  # True
print(temperature == 24)  # True
```

برای بررسی برابری مقدار از `==` استفاده می‌شود؛ `is` برای هویت شیء است و جایگزین مقایسه معمولی نیست.

## ۳. منطق بولی

`and` زمانی درست است که هر دو طرف درست باشند؛ `or` با درست‌بودن دست‌کم یک طرف درست می‌شود و `not` نتیجه را معکوس می‌کند.

```python
age = 16
has_permission = True
allowed = age >= 13 and has_permission
print(allowed)
```

این عملگرها کوتاه‌مدارند: در `A and B` اگر A نادرست باشد، B ارزیابی نمی‌شود؛ در `A or B` اگر A درست باشد، B ارزیابی نمی‌شود.

## ۴. عضویت و هویت

- `in` و `not in` عضویت یک مقدار را در رشته، فهرست، مجموعه یا دیکشنری بررسی می‌کنند.
- `is` و `is not` بررسی می‌کنند دو نام به یک شیء واحد اشاره دارند یا نه.

```python
names = ["Ava", "Mina"]
print("Mina" in names)  # True

value = None
print(value is None)    # True
```

برای بررسی `None` الگوی `is None` مناسب است.

## ۵. تقدم و پرانتز

عملگرها تقدم متفاوتی دارند. در عبارت پیچیده، برای روشن‌شدن قصد برنامه‌نویس از پرانتز استفاده کنید:

```python
result = (2 + 3) * 4
print(result)  # 20
```

به‌جای حفظ‌کردن همه قواعد، عبارت را ساده و خوانا بنویسید و در موارد مبهم پرانتز بگذارید.

## ۶. خطاهای رایج

- استفاده از `is` به‌جای `==` برای مقایسه مقدارها.
- تصور اینکه `/` و `//` نتیجه یکسان دارند.
- فراموش‌کردن تقدم عملگرها.
- مقایسه مقدارهای float با برابری دقیق، بدون توجه به دقت ممیز شناور.

## ۷. تمرین

۱. بررسی کنید عددی بر ۳ بخش‌پذیر است یا نه.
۲. شرطی بنویسید که سن در یک بازه و مجوز را هم‌زمان بررسی کند.
۳. نتیجه `-7 // 2` و `-7 % 2` را پیش‌بینی و سپس اجرا کنید.
