# مدیریت خطا و استثناها در پایتون

## ۱. خطاها چه زمانی رخ می‌دهند؟

برخی خطاها پیش از اجرای برنامه و هنگام تجزیه کد رخ می‌دهند؛ مانند تورفتگی نادرست یا جاافتادن دونقطه. گروهی دیگر در زمان اجرا رخ می‌دهند؛ مانند تقسیم بر صفر یا تبدیل متن نامعتبر به عدد. پایتون برای بسیاری از خطاهای زمان اجرا از سازوکار استثنا (Exception) استفاده می‌کند.

## ۲. مدیریت استثنا با try و except

```python
raw = input("یک عدد وارد کنید: ")

try:
    number = int(raw)
except ValueError:
    print("ورودی باید عدد صحیح باشد.")
else:
    print(f"دو برابر: {number * 2}")
```

بخش `try` کدی را در بر می‌گیرد که ممکن است استثنا ایجاد کند. بخش `except ValueError` فقط خطای تبدیل نامعتبر را مدیریت می‌کند. `else` زمانی اجرا می‌شود که در بخش try استثنایی رخ نداده باشد.

## ۳. finally

بخش `finally` چه استثنا رخ دهد چه ندهد اجرا می‌شود و برای عملیات پاک‌سازی مناسب است. برای کار با فایل‌ها اغلب استفاده از `with` ساده‌تر و ایمن‌تر است.

## ۴. استثنای مناسب را بگیرید

گرفتن عمومی `except:` یا `except Exception:` بدون دلیل روشن می‌تواند خطاهای برنامه‌نویسی را پنهان کند. نوع استثنایی را بگیرید که انتظار دارید و برای آن راه‌حل معنادار دارید.

## ۵. ایجاد استثنا

وقتی ورودی با قرارداد تابع سازگار نیست، می‌توان با `raise` استثنای مناسب ایجاد کرد:

```python
def set_age(age):
    if age < 0:
        raise ValueError("سن نمی‌تواند منفی باشد.")
    return age
```

استثنا باید نوع و پیام مناسبی داشته باشد و قرارداد تابع را روشن کند.

## ۶. زنجیره خطا

هنگام تبدیل خطای سطح پایین به خطایی معنادارتر، می‌توان علت را حفظ کرد:

```python
try:
    value = int("unknown")
except ValueError as error:
    raise RuntimeError("خواندن مقدار ناموفق بود") from error
```

این روش باعث می‌شود اطلاعات خطای اصلی از بین نرود.

## ۷. خطاهای رایج

- گرفتن همه استثناها و نادیده‌گرفتن آن‌ها.
- نمایش پیام موفقیت قبل از اطمینان از موفقیت عملیات.
- استفاده از استثنا برای کنترل عادی جریان برنامه، وقتی شرط ساده کافی است.
- نوشتن پیام خطای مبهم و بدون راهنمای اصلاح.

## ۸. تمرین

۱. برنامه‌ای بنویسید که تقسیم دو عدد را انجام دهد و ورودی نامعتبر و تقسیم بر صفر را مدیریت کند.
۲. تابعی بسازید که برای سن منفی `ValueError` ایجاد کند.
۳. توضیح دهید چرا گرفتن همه استثناها و اجرای `pass` می‌تواند اشکال‌زدایی را دشوار کند.
