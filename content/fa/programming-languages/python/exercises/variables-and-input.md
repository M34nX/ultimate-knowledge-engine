# تمرین: متغیرها، ورودی و تبدیل نوع

## هدف

دریافت ورودی متنی، تبدیل نوع و استفاده از متغیرها را تمرین کنید.

## صورت مسئله

برنامه‌ای بنویسید که نام کاربر و دو عدد صحیح را از ورودی دریافت کند. سپس مجموع دو عدد را با نام کاربر نمایش دهد.

## محدودیت‌ها

- از دو متغیر جدا برای عددها استفاده کنید.
- برای تبدیل ورودی به عدد صحیح از `int()` استفاده کنید.
- در نسخهٔ اول فرض کنید کاربر ورودی عددی معتبر وارد می‌کند.

## راهنمایی مرحله‌ای

۱. نام را با `input()` بگیرید و فاصلهٔ دو سر آن را پاک کنید.
۲. هر عدد را جداگانه دریافت و تبدیل کنید.
۳. مجموع را محاسبه و با f-string نمایش دهید.

## پاسخ پیشنهادی

```python
name = input("نام: ").strip()
first = int(input("عدد اول: "))
second = int(input("عدد دوم: "))
print(f"{name}، مجموع برابر است با {first + second}")
```

## معیار ارزیابی

پاسخ باید تبدیل نوع را درست انجام دهد، جمع عددی را با اتصال رشته اشتباه نگیرد و خروجی قابل‌فهم تولید کند. در نسخهٔ توسعه‌یافته، ورودی نامعتبر را با `try/except` مدیریت کنید.
