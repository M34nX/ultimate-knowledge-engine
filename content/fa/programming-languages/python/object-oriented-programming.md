# برنامه‌نویسی شیءگرا در پایتون

## ۱. کلاس و نمونه

کلاس (Class) قالبی برای تعریف داده و رفتار است. نمونه (Instance) شیئی است که بر اساس آن کلاس ساخته می‌شود.

```python
class Student:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade

    def passed(self):
        return self.grade >= 10

student = Student("Mina", 18)
print(student.name)
print(student.passed())
```

`__init__` هنگام ساخت نمونه فراخوانی می‌شود و ویژگی‌های آن را مقداردهی می‌کند. پارامتر `self` به نمونه فعلی اشاره دارد و هنگام فراخوانی متد نمونه، پایتون آن را به‌صورت خودکار فراهم می‌کند.

## ۲. ویژگی نمونه و ویژگی کلاس

ویژگی نمونه برای هر شیء جداگانه نگهداری می‌شود. ویژگی کلاس در سطح خود کلاس تعریف می‌شود و میان نمونه‌ها مشترک است، مگر آنکه نمونه آن را بازنویسی کند:

```python
class Counter:
    created = 0

    def __init__(self):
        Counter.created += 1
```

برای داده‌های mutable مانند فهرست، از ویژگی کلاس به‌عنوان ظرف مشترک ناخواسته استفاده نکنید.

## ۳. متدها

متد نمونه رفتار یک شیء را تعریف می‌کند. پایتون همچنین متدهای کلاس و متدهای ایستا دارد؛ آن‌ها کاربردهای متفاوتی دارند و نباید صرفاً برای پیچیده‌ترشدن طراحی استفاده شوند.

## ۴. وراثت

وراثت امکان ساخت کلاس جدید بر پایه کلاس دیگر را فراهم می‌کند:

```python
class Person:
    def __init__(self, name):
        self.name = name

class Teacher(Person):
    def teach(self):
        return f"{self.name} is teaching"
```

کلاس `Teacher` ویژگی‌های کلاس پایه را به ارث می‌برد. برای گسترش سازنده والد می‌توان از `super()` استفاده کرد.

## ۵. ترکیب در برابر وراثت

ترکیب (Composition) یعنی یک شیء از شیءهای دیگر برای انجام کار استفاده کند. اگر رابطه «دارای یک» طبیعی‌تر از «نوعی از» است، ترکیب معمولاً گزینه روشن‌تری است. وراثت را فقط برای رابطه معنایی واقعی و قابل جایگزینی انتخاب کنید.

## ۶. کپسوله‌سازی و قراردادها

در پایتون، زیرخط ابتدایی مانند `_balance` قرارداد می‌سازد که ویژگی جزئیات داخلی محسوب می‌شود. این قرارداد به‌تنهایی سازوکار امنیتی نیست. رابط عمومی کلاس باید روشن و پایدار باشد.

## ۷. خطاهای رایج

- فراموش‌کردن `self` در تعریف متد نمونه.
- استفاده از فهرست mutable به‌عنوان مقدار پیش‌فرض یا ویژگی کلاس مشترک، بدون قصد.
- ساخت سلسله‌مراتب وراثت عمیق برای مسئله‌ای ساده.
- قرار دادن همه منطق برنامه در کلاس‌ها، حتی وقتی تابع ساده مناسب‌تر است.

## ۸. تمرین

۱. کلاس `Book` با عنوان، نویسنده و متد نمایش اطلاعات بسازید.
۲. کلاس `BankAccount` آزمایشی با متد واریز و برداشت طراحی کنید و برداشت نامعتبر را مدیریت کنید.
۳. برای مدل کردن «کتابخانه‌ای دارای چند کتاب»، ترکیب را به‌کار ببرید و دلیل انتخاب را توضیح دهید.
