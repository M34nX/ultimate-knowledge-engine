# آشنایی با توابع در پایتون

> **نمونه آموزشی در وضعیت پیش‌نویس.** این صفحه قالب محتوای پروژه را نشان می‌دهد و هنوز بازبینی علمی و فنی کامل نشده است.

## ۱. تابع چیست؟

تابع (Function) بخشی نام‌گذاری‌شده و قابل استفاده مجدد از منطق برنامه است. تابع می‌تواند ورودی دریافت کند، کاری انجام دهد و در صورت نیاز نتیجه‌ای برگرداند.

توابع به برنامه‌نویس کمک می‌کنند مسئله‌های بزرگ را به بخش‌های کوچک‌تر تقسیم کند، برای عملیات نام معنادار انتخاب کند و از تکرار غیرضروری کد بکاهد.

## ۲. تعریف و فراخوانی تابع

```python
def greet(name):
    message = f"Hello, {name}!"
    return message

result = greet("Ada")
print(result)
```

خروجی مورد انتظار:

```text
Hello, Ada!
```

دستور `def` تابع را تعریف می‌کند. دستورات تورفته، بدنه تابع را تشکیل می‌دهند. فراخوانی `greet("Ada")` تابع را با آرگومان داده‌شده اجرا می‌کند.

## ۳. تفاوت پارامتر و آرگومان

**پارامتر (Parameter)** نامی است که در تعریف تابع نوشته می‌شود؛ مانند `name`. **آرگومان (Argument)** مقداری است که هنگام فراخوانی به تابع داده می‌شود؛ مانند `"Ada"`.

## ۴. مقدار بازگشتی

دستور `return` اجرای فراخوانی فعلی تابع را پایان می‌دهد و نتیجه را به محل فراخوانی بازمی‌گرداند. تابعی که بدون دستور return صریح پایان یابد، مقدار `None` را برمی‌گرداند.

## ۵. اشتباهات رایج

- تعریف تابع بدون فراخوانی آن.
- اشتباه گرفتن نام پارامتر با مقدار آرگومان.
- تصور اینکه `print()` متن نمایش‌داده‌شده را برمی‌گرداند.
- فراموش‌کردن تورفتگی در بدنه تابع.
- استفاده از متغیر محلی در خارج از محدوده‌ای که تعریف شده است.

## ۶. تمرین

۱. تابعی به نام `square` تعریف کنید که مربع یک عدد را برگرداند.

۲. تابعی تعریف کنید که نام کوچک را دریافت کند و یک پیام خوشامدگویی برگرداند.

۳. تفاوت چاپ‌کردن یک مقدار و بازگرداندن آن را توضیح دهید.
