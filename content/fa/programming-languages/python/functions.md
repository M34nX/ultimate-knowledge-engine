# توابع در پایتون؛ از تعریف تا طراحی درست

## ۱. چرا تابع؟

تابع (Function) یک واحد نام‌گذاری‌شده از منطق برنامه است. با تابع می‌توان مسئله بزرگ را به کارهای کوچک تقسیم کرد، از تکرار کد جلوگیری کرد و برای هر کار یک نام روشن انتخاب کرد. تابع خوب معمولاً یک مسئولیت مشخص دارد.

## ۲. تعریف و فراخوانی

```python
def greet(name):
    message = f"سلام، {name}"
    return message

result = greet("آوا")
print(result)
```

کلمه کلیدی `def` تابع را تعریف می‌کند. بدنه تابع با تورفتگی مشخص می‌شود. تعریف تابع به‌تنهایی آن را اجرا نمی‌کند؛ باید آن را فراخوانی کرد.

## ۳. پارامتر و آرگومان

پارامتر نامی است که در تعریف تابع می‌آید؛ `name` در مثال بالا پارامتر است. آرگومان مقدار واقعی‌ای است که هنگام فراخوانی داده می‌شود؛ `"آوا"` آرگومان است.

## ۴. مقدار بازگشتی و print

`return` نتیجه را به محل فراخوانی بازمی‌گرداند و اجرای تابع را پایان می‌دهد. `print()` فقط مقداری را برای نمایش می‌فرستد و به‌خودی‌خود جایگزین return نیست.

```python
def square(number):
    return number * number

answer = square(5)
print(answer)  # 25
```

تابعی که بدون return صریح به پایان برسد، مقدار `None` را برمی‌گرداند.

## ۵. چند آرگومان و آرگومان نام‌دار

```python
def describe_book(title, author, year):
    return f"{title} — {author} ({year})"

print(describe_book("Dune", "Frank Herbert", 1965))
print(describe_book(author="Ursula Le Guin", title="A Wizard of Earthsea", year=1968))
```

در فراخوانی نام‌دار، ارتباط مقدار و پارامتر آشکارتر است. پس از آرگومان نام‌دار نمی‌توان آرگومان موقعیتی معمولی آورد.

## ۶. مقدار پیش‌فرض

```python
def greet(name, prefix="سلام"):
    return f"{prefix}، {name}"

print(greet("مینا"))
print(greet("رضا", prefix="درود"))
```

پارامترهای دارای مقدار پیش‌فرض باید پس از پارامترهای بدون مقدار پیش‌فرض قرار بگیرند. از فهرست یا دیکشنری mutable به‌عنوان مقدار پیش‌فرض استفاده نکنید مگر رفتار مشترک و ماندگار آن را آگاهانه بخواهید.

## ۷. محدوده متغیرها

متغیری که داخل تابع تعریف می‌شود معمولاً محلی است و از بیرون تابع قابل دسترسی مستقیم نیست:

```python
def calculate():
    total = 10
    return total

print(calculate())
```

برای فهم محدوده نام‌ها، پایتون از قاعده LEGB استفاده می‌کند: Local، Enclosing، Global و Built-in. تغییر متغیر سراسری از داخل تابع معمولاً طراحی را دشوار می‌کند؛ انتقال داده از طریق آرگومان و return اغلب روشن‌تر است.

## ۸. مستندسازی و طراحی

برای تابعی که رابط عمومی دارد، docstring بنویسید:

```python
def area_rectangle(width, height):
    """مساحت مستطیل را برای ضلع‌های نامنفی برمی‌گرداند."""
    if width < 0 or height < 0:
        raise ValueError("ضلع‌ها نمی‌توانند منفی باشند.")
    return width * height
```

نام تابع باید کنش یا نتیجه را نشان دهد. ورودی‌های لازم را روشن کنید، حالت نامعتبر را مدیریت کنید و تابع را تا حد امکان کوتاه و مستقل نگه دارید.

## ۹. اشتباهات رایج

- تعریف تابع و فراموش‌کردن فراخوانی.
- اشتباه‌گرفتن پارامتر و آرگومان.
- انتظار مقدار از تابعی که فقط print اجرا می‌کند.
- استفاده از متغیر محلی بیرون تابع.
- قراردادن فهرست mutable به‌عنوان مقدار پیش‌فرض.
- نوشتن تابعی با چند مسئولیت نامرتبط.

## ۱۰. تمرین

۱. تابع `rectangle_area` را بنویسید که دو ضلع را بگیرد و مساحت را برگرداند.
۲. تابع `format_name` را با پارامتر اختیاری برای نام میانی طراحی کنید.
۳. تابعی برای میانگین فهرست عددها بنویسید؛ برای فهرست خالی رفتار مشخصی تعیین کنید.
۴. برای تابع میانگین، آزمون ورودی معمول و ورودی خالی بنویسید.
