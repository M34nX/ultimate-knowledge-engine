# علوم کامپیوتر

**شناسه حوزه:** 02  
**وضعیت:** برنامه‌ریزی‌شده

مبانی محاسبات: نمایش مسئله‌ها، طراحی الگوریتم‌ها، اندازه‌گیری منابع و شناخت رفتار سیستم‌ها.

## نقشه موضوعات

- الگوریتم‌ها و تحلیل الگوریتم.
- ساختمان داده‌ها و انواع داده انتزاعی.
- پیچیدگی، نمادگذاری مجانبی و مصالحه‌ها.
- ریاضیات گسسته، منطق، مجموعه‌ها، روابط و گراف‌ها.
- اتوماتا، زبان‌های صوری، محاسبه‌پذیری و نظریه پیچیدگی.
- کامپایلرها، مفسرها و نظریه زبان‌های برنامه‌نویسی.
- محاسبات توزیع‌شده و مدل‌های بنیادین.
- نظریه اطلاعات و نمایش عددی.

## استاندارد آموزش

شهود، تعریف رسمی، مثال حل‌شده، فرض‌های تحلیل و برداشت‌های نادرست رایج باید توضیح داده شوند. پیچیدگی الگوریتم بدون مشخص‌کردن مدل تحلیل و اندازه ورودی بیان نشود.
