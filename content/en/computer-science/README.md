# Computer Science

**Domain ID:** 02  
**Status:** Planned content area

The foundations of computation: how problems are represented, algorithms are designed, resources are measured, and systems behave.

## Topic map

- Algorithms and algorithm analysis.
- Data structures and abstract data types.
- Complexity, asymptotic notation, and trade-offs.
- Discrete mathematics, logic, sets, relations, and graphs.
- Automata, formal languages, computability, and complexity theory.
- Compilers, interpreters, and programming-language theory.
- Distributed computing and foundational models.
- Information theory and numerical representation.

## Teaching standard

Explain intuition, formal definitions, worked examples, complexity assumptions, and common misconceptions. Avoid presenting an algorithm's complexity without stating the relevant model and input measure.
