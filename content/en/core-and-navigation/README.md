# Core & Navigation

**Domain ID:** 00  
**Status:** Planned content area

This domain explains how to use the knowledge system and how to learn technical subjects effectively.

## Topics

- How to navigate UKE and interpret content status.
- Learning strategies, deliberate practice, and self-assessment.
- Prerequisites, learning objectives, and skill maps.
- Technical reading, documentation literacy, and source evaluation.
- Git, contribution workflow, and project conventions.
- Responsible use of AI-assisted learning.
