# Cybersecurity

**Domain ID:** 08  
**Status:** Planned content area

This domain teaches defensive security concepts and secure engineering practices.

## Topic map

- Security principles, threat modelling, and risk.
- Secure coding and input validation.
- Authentication, authorisation, and session management.
- Cryptography concepts and correct use of established libraries.
- Web and application security.
- Dependency, supply-chain, and secrets management.
- Privacy, data protection, and secure configuration.
- Logging, incident response concepts, and vulnerability remediation.

## Safety boundary

Content is defensive, lawful, and educational. It must not provide instructions for harming systems, evading detection, stealing credentials, or accessing systems without permission. Practical testing must be limited to owned or explicitly authorised environments.
