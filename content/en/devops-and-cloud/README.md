# DevOps & Cloud

**Domain ID:** 07  
**Status:** Planned content area

This domain covers reliable software delivery and the operation of applications and infrastructure.

## Topic map

- Version control and collaborative workflows.
- Build systems and continuous integration.
- Continuous delivery and deployment strategies.
- Containers and orchestration concepts.
- Infrastructure as code and configuration management.
- Cloud fundamentals and service models.
- Monitoring, logging, tracing, and observability.
- Reliability engineering, backups, and disaster recovery.
- Cost awareness and sustainable operations.

## Teaching standard

Examples should use safe, non-production environments. Explain permissions, costs, failure recovery, and security implications before operational procedures.
