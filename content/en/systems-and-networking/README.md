# Systems & Networking

**Domain ID:** 06  
**Status:** Planned content area

This domain explains how software interacts with hardware, operating systems, networks, and distributed infrastructure.

## Topic map

- Digital logic and computer architecture.
- CPU, memory hierarchy, storage, and I/O.
- Operating-system concepts, processes, threads, and scheduling.
- Filesystems, permissions, and system interfaces.
- Networking models, addressing, routing, and DNS.
- TCP, UDP, HTTP, TLS, and network diagnostics.
- Concurrency, parallelism, and distributed systems.
- Virtualisation and performance fundamentals.

## Teaching standard

Separate conceptual models from implementation details. Mark platform, operating-system, protocol, and hardware dependencies clearly.
