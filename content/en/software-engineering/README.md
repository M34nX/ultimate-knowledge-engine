# Software Engineering

**Domain ID:** 03  
**Status:** Planned content area

Software engineering covers the disciplined process of specifying, designing, building, testing, deploying, and maintaining software systems.

## Topic map

- Requirements, user stories, and acceptance criteria.
- Design principles, modularity, cohesion, and coupling.
- Architecture styles and architectural decision records.
- Design patterns and refactoring.
- Testing strategy, test design, and quality assurance.
- Reliability, observability, and maintainability.
- Code review, version control, and team workflows.
- Technical debt, documentation, and software lifecycle.

## Teaching standard

Present trade-offs rather than universal rules. Separate a pattern's intent from its implementation and discuss when a technique is unsuitable.
