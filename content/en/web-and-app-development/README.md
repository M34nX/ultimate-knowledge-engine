# Web & App Development

**Domain ID:** 04  
**Status:** Planned content area

This domain covers the technologies and engineering practices used to build web, mobile, and client applications.

## Topic map

- HTML, CSS, browser platform, and accessibility.
- JavaScript, TypeScript, and frontend architecture.
- Backend services, APIs, authentication concepts, and integration.
- HTTP, URLs, browsers, rendering, and web performance.
- Mobile development for major platforms.
- State management, testing, and build tooling.
- User experience engineering and internationalisation.
- Deployment and application security fundamentals.

## Teaching standard

Distinguish web standards from browser-specific behaviour, framework conventions, and hosting-provider features. Include accessibility and security considerations where relevant.
