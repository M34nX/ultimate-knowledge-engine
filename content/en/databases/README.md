# Databases

**Domain ID:** 09  
**Status:** Planned content area

This domain covers the theory and engineering of persistent data systems.

## Topic map

- Data modelling, entities, relationships, and constraints.
- Relational algebra and relational database concepts.
- SQL queries, joins, aggregation, and window functions.
- Transactions, isolation, consistency, and concurrency control.
- Indexes, query planning, and performance analysis.
- Document, key-value, graph, wide-column, and time-series systems.
- Replication, partitioning, backups, and recovery.
- Data integrity, migrations, and operational security.

## Teaching standard

Distinguish SQL language features from vendor-specific extensions. State database engine and version when behaviour differs. Explain correctness and consistency trade-offs alongside performance.
