# Mathematics for Computing

**Domain ID:** 10  
**Status:** Planned content area

This domain provides the mathematical foundations used in computer science, programming, data science, and engineering.

## Topic map

- Propositional and predicate logic.
- Sets, functions, relations, and proof techniques.
- Discrete mathematics and combinatorics.
- Graph theory and trees.
- Number systems, modular arithmetic, and cryptographic foundations.
- Linear algebra and numerical methods.
- Probability, statistics, and information theory.
- Calculus and optimisation where relevant to computing.

## Teaching standard

Define notation, state assumptions, show intermediate reasoning, and distinguish an intuitive explanation from a formal proof. Include prerequisites and worked examples.
