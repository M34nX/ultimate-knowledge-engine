# نقشهٔ توسعهٔ آموزشی مخزن UKE

**وضعیت سند:** پیشنهاد و backlog؛ این فهرست به معنی تولید یا تأییدشدن درس‌ها نیست.

هدف این سند تبدیل ۱۲ حوزهٔ مخزن به مسیرهای آموزشی پیوسته است. هر مسیر باید از مفاهیم پایه شروع شود، تمرین مرحله‌ای داشته باشد و با یک پروژه یا ارزیابی قابل سنجش پایان یابد.

## اولویت صفر — زیرساخت مشترک همهٔ دوره‌ها

پیش از گسترش تعداد درس‌ها، هر دوره باید این اجزا را داشته باشد:

- صفحهٔ معرفی شامل مخاطب، پیش‌نیاز، نتیجهٔ قابل سنجش و سطح؛
- ترتیب درس‌ها با شناسهٔ پایدار و لینک معتبر؛
- مثال حل‌شده با ورودی و خروجی مشخص؛
- تمرین مستقل و راهنمایی تدریجی؛
- پاسخ تشریحی یا معیار ارزیابی؛
- پروژهٔ پایانی با مراحل و معیار پذیرش؛
- منابع رسمی و محدودهٔ نسخه؛
- وضعیت Draft / Reviewed / Verified / Published به‌صورت صادقانه.

## نقشهٔ ۱۲ حوزه

### ۰۰ — مبانی و راهبری

**دوره‌های پیشنهادی**
1. سواد دیجیتال و کار با محیط توسعه: فایل، مسیر، ترمینال، ویرایشگر و خط فرمان.
2. یادگیری برنامه‌نویسی: تجزیه مسئله، شبه‌کد، آزمون مثال و اشکال‌زدایی.
3. کار تیمی و Git: commit، branch، merge، pull request و حل تعارض.

**پروژه‌ها و آزمایشگاه‌ها:** ساخت محیط توسعهٔ شخصی؛ نگهداری دفترچهٔ یادگیری با Git؛ شبیه‌سازی گردش کار یک تیم کوچک.

### ۰۱ — زبان‌های برنامه‌نویسی

**دوره‌های پیشنهادی**
1. پایتون از صفر تا سطح میانی: نوع داده، کنترل جریان، تابع، ساختار داده، فایل، ماژول و آزمون.
2. JavaScript برای وب: زبان پایه، DOM، رویداد، async، ماژول و کار با API.
3. مبانی زبان‌ها و پارادایم‌ها: کامپایل و تفسیر، نوع ایستا و پویا، شیءگرایی و تابعی.

**پروژه‌ها و آزمایشگاه‌ها:** مدیر کتابخانهٔ شخصی؛ بازی حدس عدد؛ مقایسهٔ یک الگوریتم در سه زبان.

### ۰۲ — علوم کامپیوتر

**دوره‌های پیشنهادی**
1. الگوریتم و تحلیل پیچیدگی: جست‌وجو، مرتب‌سازی، بازگشت و Big-O.
2. ساختمان داده: آرایه، پشته، صف، فهرست پیوندی، درخت و گراف.
3. ریاضیات گسسته برای رایانش: منطق، مجموعه، رابطه، شمارش و استقرا.

**پروژه‌ها و آزمایشگاه‌ها:** بصری‌ساز مرتب‌سازی؛ پیاده‌سازی صف و پشته؛ مسیریاب گراف با دادهٔ ساختگی.

### ۰۳ — مهندسی نرم‌افزار

**دوره‌های پیشنهادی**
1. تحلیل نیازمندی و طراحی: مسئله، کاربر، نیازمندی عملکردی و غیرعملکردی.
2. طراحی نرم‌افزار: ماژولاریتی، جداسازی مسئولیت، الگوهای طراحی و بدهی فنی.
3. کیفیت و نگهداری: آزمون واحد، یکپارچه، بازبینی کد، CI و مستندسازی.

**پروژه‌ها و آزمایشگاه‌ها:** بازطراحی یک برنامهٔ تک‌فایلی؛ نوشتن test plan؛ بررسی یک pull request نمونه.

### ۰۴ — توسعهٔ وب و اپلیکیشن

**دوره‌های پیشنهادی**
1. مبانی وب: HTML معنایی، CSS، JavaScript، شبکه و HTTP.
2. فرانت‌اند: مؤلفه‌ها، state، فرم، دسترس‌پذیری و آزمون رابط.
3. بک‌اند و API: مسیرها، اعتبارسنجی، احراز هویت مفهومی، پایگاه داده و logging.

**پروژه‌ها و آزمایشگاه‌ها:** وب‌سایت شخصی دسترس‌پذیر؛ فهرست کارهای روزانه؛ API یادداشت‌ها با دادهٔ آزمایشی.

### ۰۵ — هوش مصنوعی و علم داده

**دوره‌های پیشنهادی**
1. آمار و تحلیل داده: توصیف داده، احتمال، نمونه‌گیری و عدم قطعیت.
2. یادگیری ماشین پایه: ویژگی، برچسب، تفکیک داده، آموزش، اعتبارسنجی و معیارها.
3. یادگیری عمیق و هوش مصنوعی مسئولانه: شبکهٔ عصبی، overfitting، سوگیری، حریم خصوصی و ارزیابی.

**پروژه‌ها و آزمایشگاه‌ها:** تحلیل مجموعه‌دادهٔ عمومی؛ مدل پیش‌بینی ساده با دادهٔ آموزشی؛ گزارش خطا و سوگیری مدل.

### ۰۶ — سیستم‌ها و شبکه

**دوره‌های پیشنهادی**
1. معماری رایانه: نمایش عدد، CPU، حافظه، cache و ورودی/خروجی.
2. سیستم‌عامل: فرایند، thread، حافظهٔ مجازی، فایل‌سیستم و زمان‌بندی.
3. شبکه: لایه‌ها، IP، DNS، TCP، TLS و HTTP.

**پروژه‌ها و آزمایشگاه‌ها:** شبیه‌ساز زمان‌بندی فرایند؛ مدل‌سازی cache؛ تحلیل درخواست HTTP محلی.

### ۰۷ — دواپس و رایانش ابری

**دوره‌های پیشنهادی**
1. خط فرمان و اسکریپت‌نویسی برای خودکارسازی.
2. Git workflow و CI/CD با pipelineهای کوچک.
3. کانتینر، زیرساخت به‌صورت کد، پایش و مدیریت هزینه.

**پروژه‌ها و آزمایشگاه‌ها:** pipeline آزمون یک پروژه؛ بسته‌بندی یک برنامهٔ محلی؛ داشبورد پایش ساختگی.

### ۰۸ — امنیت سایبری

**دوره‌های پیشنهادی**
1. مبانی امنیت و مدل‌سازی تهدید: دارایی، تهدید، آسیب‌پذیری و ریسک.
2. توسعهٔ امن: اعتبارسنجی ورودی، مدیریت نشست، کنترل دسترسی و ثبت رویداد.
3. رمزنگاری کاربردی و حریم خصوصی: hash، امضای دیجیتال، TLS و مدیریت کلید در سطح مفهومی.

**پروژه‌ها و آزمایشگاه‌ها:** بازبینی امنیتی کد ساختگی؛ طراحی چک‌لیست ورودی امن؛ تمرین threat modeling برای یک اپ فرضی. همهٔ آزمایش‌ها باید در محیط محلی و مجاز باشند.

### ۰۹ — پایگاه‌های داده

**دوره‌های پیشنهادی**
1. مدل‌سازی رابطه‌ای و طراحی schema.
2. SQL از پایه تا join، group by، زیرپرس‌وجو و window function.
3. تراکنش، index، query plan، backup و بازیابی.

**پروژه‌ها و آزمایشگاه‌ها:** طراحی پایگاه دادهٔ کتابخانه؛ تحلیل plan پرس‌وجو؛ شبیه‌سازی تراکنش بانکی با دادهٔ ساختگی.

### ۱۰ — ریاضیات برای رایانش

**دوره‌های پیشنهادی**
1. منطق و ریاضیات گسسته.
2. جبر خطی و بردارها برای گرافیک و یادگیری ماشین.
3. احتمال، آمار و روش‌های عددی.

**پروژه‌ها و آزمایشگاه‌ها:** بصری‌سازی بردار؛ شبیه‌سازی احتمال با نمونه‌های تصادفی؛ تحلیل خطای تقریب عددی.

### ۱۱ — پروژه‌ها و پژوهش

**دوره‌های پیشنهادی**
1. تفکر علمی و طراحی پرسش پژوهشی.
2. خواندن مقاله، بررسی منبع، بازتولید نتایج و گزارش محدودیت‌ها.
3. مدیریت پروژهٔ فنی، تعریف دامنه، milestone و ارزیابی نتیجه.

**پروژه‌ها و آزمایشگاه‌ها:** بازتولید یک نتیجهٔ کوچک با دادهٔ عمومی؛ نوشتن گزارش فنی؛ مقایسهٔ دو راه‌حل با معیارهای روشن.

## ایده‌های سراسری برای قابلیت‌های آینده

این موارد باید پس از تثبیت محتوای پایه و در قالب issueهای مستقل طراحی شوند:

- جست‌وجوی معنایی که نتیجه را به درس و منبع دقیق پیوند دهد؛
- نمودار پیش‌نیازها و مسیرهای جایگزین برای هر مهارت؛
- آزمایشگاه تعاملی الگوریتم با ورودی قابل تغییر؛
- آزمون‌های تشخیصی برای تعیین پیش‌نیازهای ازدست‌رفته؛
- کارت‌های مرور فاصله‌دار بر پایهٔ مفهوم، نه صرفاً حفظ جمله؛
- مقایسهٔ نسخه‌ها و نشان‌دادن محتوای منسوخ؛
- داشبورد کیفیت که Draft را از Verified جدا کند؛
- مسیرهای پروژه‌محور برای دانش‌آموز، دانشجو و توسعه‌دهندهٔ خودآموز؛
- پشتیبانی بهتر از راست‌به‌چپ، زیرنویس و متن جایگزین در محتوای چندرسانه‌ای.

## معیار پذیرش یک دورهٔ کامل

دوره زمانی «کاملِ نسخهٔ نخست» محسوب می‌شود که تمام درس‌های فهرست‌شده محتوا و منابع داشته باشند، تمام لینک‌ها کار کنند، تمرین‌های کافی با معیار پاسخ وجود داشته باشد، دست‌کم یک پروژهٔ پایانی قابل اجرا تعریف شود، پیش‌نیازها به محتوای موجود اشاره کنند و وضعیت بازبینی هر بخش شفاف باشد. کامل‌بودن دوره به معنی پوشش تمام دانش آن حوزه نیست.
