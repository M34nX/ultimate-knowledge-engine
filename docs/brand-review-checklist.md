# Brand and UI Review Checklist

Use this checklist for any change that affects shared visual presentation.

## Identity
- [ ] Uses the approved UKE symbol or wordmark without distortion.
- [ ] Uses the canonical token names and values.
- [ ] Does not introduce a competing accent palette.
- [ ] Repository Markdown remains readable on GitHub.

## Layout and responsive behavior
- [ ] Works on narrow mobile screens and wide displays.
- [ ] Maintains readable line length and spacing.
- [ ] Navigation and key actions remain discoverable.
- [ ] No horizontal overflow except intentionally scrollable data/code regions.

## Accessibility
- [ ] Text and controls meet the WCAG 2.2 AA contrast target.
- [ ] Keyboard focus is visible and not obscured.
- [ ] Controls have accessible names and labels.
- [ ] Meaning is not conveyed by color alone.
- [ ] Reduced-motion preference is respected.

## Localization
- [ ] English LTR layout reviewed.
- [ ] Persian RTL layout reviewed.
- [ ] Code, URLs, file paths, and identifiers remain correctly directed.
- [ ] Mixed-script punctuation and numbers are legible.

## Integrity
- [ ] No feature is presented as implemented when it is only planned.
- [ ] No content status is overstated.
- [ ] Screenshots and sample data are clearly illustrative where applicable.
