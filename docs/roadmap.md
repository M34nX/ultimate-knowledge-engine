# Roadmap

This roadmap is directional. Items become commitments only when an issue or milestone defines scope and acceptance criteria.

## Phase 1 — Foundation

- Repository architecture and navigation.
- Editorial, citation, translation, and contribution standards.
- Initial registries, schemas, and templates.
- A small reference-quality sample set in English and Persian.

## Phase 2 — Content pipeline

- Schema and frontmatter validation.
- Link and source checks.
- Translation parity checks.
- Code-example test harness for supported languages.
- Automated quality reports.

## Phase 3 — Reference content

- Python and JavaScript as initial reference language guides.
- Core computer-science concepts.
- Shared terminology and syntax dictionary.
- Curated official documentation catalogue.

## Phase 4 — Web encyclopedia

- Documentation site generated from canonical content.
- Localised navigation and RTL support.
- Search and source display.
- Accessibility and responsive testing.

## Phase 5 — Expansion

- Additional languages, frameworks, and domains.
- More exercises, assessments, and projects.
- Cross-language comparisons and knowledge graph.

## Phase 6 — Interactive learning

- Algorithm and data-structure visualisations.
- Safe, isolated code playground.
- Learning progress and spaced review, subject to privacy design.

## Phase 7 — Advanced intelligence

- Semantic search.
- AI-assisted explanations with source grounding and clear limitations.
- Adaptive learning recommendations.
- Offline and research-oriented capabilities.

## Prioritisation

Prefer a small, verified learning path over a large collection of shallow, unreviewed pages. Each phase must be supportable by maintainers and automated checks.
