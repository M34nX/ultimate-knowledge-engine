# Writing and Teaching Standard

## Audience

Write for a curious learner. Assume no unstated prerequisite. Define specialised terms before relying on them.

## Explanation pattern

Where appropriate, teach in layers:
1. intuitive explanation;
2. precise definition;
3. technical mechanism;
4. worked example;
5. limitations and common mistakes;
6. practice and further links.

## Style

- Use direct, precise language.
- Prefer short paragraphs and descriptive headings.
- Explain why a feature exists, not only how to type it.
- Distinguish facts, conventions, recommendations, and unresolved questions.
- Avoid unsupported superlatives and absolute claims.
- Use consistent terminology within each locale.
- Do not pad pages with unrelated sections.

## Code

Use fenced code blocks with an explicit language identifier. Keep examples focused and show expected output when useful. Identify version requirements. Never use secrets or real personal data in examples.
