# Citation and Source Standard

## Preferred source order

1. Official language, framework, platform, or standards documentation.
2. Primary specifications, proposals, and original research.
3. Maintainer-authored technical material.
4. Reputable textbooks and peer-reviewed educational resources.
5. Reputable secondary explanations, used for context rather than as sole authority.

## Record for each source

Where applicable, record title, publisher/maintainer, canonical URL, source type, version/date, access date, relevant section, licence, and reliability notes.

## Claim-level traceability

Readers should be able to identify which source supports a technical claim. Cite near the claim rather than collecting unrelated links at the end.

## Time-sensitive claims

Popularity rankings, current versions, platform behaviour, release dates, and security advisories must be dated and rechecked. Do not present old statistics as current.

## Reuse

A citation is not a licence. Linking to a source and reproducing its material are different acts. Check permission before copying prose, diagrams, screenshots, code, or datasets.
