# Translation Standard

Translation is editorial work. It must preserve technical meaning, teaching sequence, examples, warnings, and level of detail.

## Rules

- Keep the stable content ID across locales.
- Use the locale's approved terminology glossary.
- Retain English technical terms when they are the clearest identifiers; add a local equivalent on first use where useful.
- Do not translate code identifiers, APIs, commands, filenames, or compiler output unless the lesson explicitly teaches localisation.
- Adapt examples only when necessary and document material changes.
- Keep links and version scope aligned with the source page.
- Mark machine-assisted text as unreviewed until a qualified human checks it.

## Translation parity

Track missing sections and stale translations. A source-page update should flag dependent translations for review. Never mark a locale complete merely because a translated file exists.
