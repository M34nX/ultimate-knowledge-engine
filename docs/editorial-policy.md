# Editorial Policy

## Mission

Publish technical knowledge that is accurate, understandable, useful, source-backed, and maintainable.

## Accuracy

Prefer official documentation and primary sources. Separate facts from recommendations and opinions. State uncertainty and known limitations.

## Completeness

A page is complete when it meets its learning or reference purpose, not when every possible heading is filled. Avoid artificial length and repeated explanations.

## Neutrality

Compare technologies using explicit criteria. Avoid unsupported rankings, marketing language, and fan-based arguments.

## Currency

Version and date claims that can change. Review fast-changing subjects more frequently than stable fundamentals.

## Safety and security

Keep security content defensive, lawful, and educational. Examples must not encourage unsafe real-world use. Follow the repository security policy.

## AI assistance

AI may help with drafting, translation suggestions, or discovery in future workflows, but it is not an authority. A human reviewer remains accountable for correctness, citations, licensing, and learner safety.

## Corrections

Correct material errors transparently. When a correction changes a key recommendation or technical conclusion, note it in the change history.
