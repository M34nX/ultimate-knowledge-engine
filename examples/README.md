# Examples

Examples should be small, reproducible, focused, and tied to a concept or lesson.

## Requirements

- Identify the language and tested version.
- Include expected output where helpful.
- Avoid secrets, personal data, destructive commands, and hidden environmental dependencies.
- Explain any omitted error handling or simplification.
- Keep examples consistent between locales unless localisation is being taught.

Executable examples must be tested in a disposable and restricted environment before being marked verified.
