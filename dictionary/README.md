# Technical Dictionary

The dictionary is the reference layer of UKE. It is organised around stable, reusable knowledge units rather than one giant glossary page.

## Collections

- **Concepts:** foundational and advanced ideas.
- **Terminology:** bilingual terms, definitions, pronunciation, usage, and related terms.
- **Syntax:** language grammar, operators, expressions, declarations, and statements.
- **Built-ins:** built-in functions, types, constants, and special methods.
- **Standard libraries:** modules and APIs grouped by language and version.
- **Errors:** error classes, diagnostics, causes, and safe debugging approaches.

## Entry quality

A strong entry should define the term, explain it at multiple levels, show a minimal example, identify common misconceptions, link related concepts, state version constraints, and cite authoritative sources.

Not every field applies to every entry. Avoid artificial sections.
