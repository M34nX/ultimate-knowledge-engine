# Registries

Registries are the structured index of what UKE intends to cover.

- `domains.yaml`: the top-level knowledge taxonomy.
- `languages.yaml`: programming languages and related technical languages/formats.
- `locales.yaml`: supported and planned content locales.
- `resources.yaml`: curated external sources.

A registry entry indicates tracked scope, not a completed guide, endorsement, popularity ranking, or quality guarantee. Keep each category semantically precise and record the evidence behind time-sensitive classifications.
