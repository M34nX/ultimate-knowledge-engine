# GitHub Repository Catalogue

This catalogue tracks external repositories that are useful for learning, reference, tooling, or examples.

For each repository, record:
- canonical repository URL and owner;
- purpose and relevant topics;
- activity and maintenance signals, checked on a specific date;
- default branch and release/version where relevant;
- licence and reuse constraints;
- whether UKE links to it, depends on it, or includes permitted material.

Do not mirror or bulk-copy repositories simply because they are public. Prefer linking, package dependencies, or submodules where appropriate.
