# References and External Resources

This directory tracks documentation, specifications, books, courses, papers, and other external learning resources.

## Rules

- Prefer canonical and primary sources.
- Record provenance, access date, version, and licence information when applicable.
- Separate a recommendation from an endorsement.
- Recheck fast-changing resources.
- Treat a source link as a pointer, not permission to reproduce the source.

The initial curated catalogue is in [registry/resources.yaml](../registry/resources.yaml).
