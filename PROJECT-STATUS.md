# Project Status

**Stage:** Foundation / v0.1.0  
**Status:** Initial construction  
**Status date:** 2026-11-18

This page distinguishes repository foundations from future plans. A listed capability is not delivered until the content, tests, and documentation exist.

## Foundation scope

- Repository information architecture.
- Initial domain, language, and locale registries.
- Editorial, source, translation, accessibility, and contribution standards.
- Initial content schemas and templates.
- English and Persian starter content examples.

## Planned, not yet delivered

- Full learning content for all registered languages.
- Full multilingual translation coverage.
- Production web encyclopedia.
- Semantic search and knowledge graph service.
- Interactive execution and visual simulators.
- Learner accounts, progress tracking, and adaptive learning.
- AI-assisted tutoring.
- Comprehensive automated validation and CI coverage.

## Definition of done

A capability is delivered only when it has an agreed scope, implementation or authored content, documentation, appropriate validation, relevant accessibility/security review, and an honest status in this file or the roadmap.
