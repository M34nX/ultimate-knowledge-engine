# Project Status

**Current published baseline:** v0.1.0  
**Next development target:** v0.2.0  
**Status:** Foundation with an expanding draft learning academy  
**Status date:** 2026-11-18

This page distinguishes published foundations from work in progress. A listed capability is not production-ready merely because a folder, registry entry, or draft lesson exists.

## Delivered foundation

- Repository information architecture and 12 top-level knowledge domains.
- Initial language and locale registries.
- Editorial, source, translation, accessibility, and contribution standards.
- Initial content schemas and templates.
- English and Persian starter content.
- Build from Scratch starter tracks for AI, 2D game development, and operating-system concepts.
- Additional bilingual draft tracks for database engines, compilers, local network services, and search engines.
- A direct-link academy catalogue with planned categories clearly separated from available draft lessons.

## In progress for v0.2.0

- Expand and review the Build from Scratch curriculum.
- Improve README navigation and repository presentation.
- Add automated checks for internal links, translation parity, lesson metadata, and code examples.
- Verify all new external references and technical examples.
- Establish release notes and a repeatable release checklist.

## Planned, not yet delivered

- Full learning content for all registered languages.
- Full multilingual translation coverage.
- Production web encyclopedia.
- Semantic search and knowledge graph service.
- Interactive code execution and visual simulators.
- Learner accounts, progress tracking, and adaptive learning.
- AI-assisted tutoring.
- Comprehensive automated validation and CI coverage.

## Definition of done

A capability is delivered only when it has an agreed scope, implementation or authored content, documentation, appropriate validation, relevant accessibility/security review, and an honest status here or in the roadmap. A version is released only after its acceptance checks pass and its release tag is created.
