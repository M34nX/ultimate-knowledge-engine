# Learning Academy

The learning layer turns reference material into sequenced learning experiences.

## Collections

- **Roadmaps:** prerequisite-aware journeys toward a defined capability.
- **Courses:** ordered groups of lessons.
- **Lessons:** focused instruction with measurable objectives.
- **Exercises:** practice tasks with hints and assessment criteria.
- **Quizzes:** checks for recall and conceptual understanding.
- **Projects:** applied work with requirements and acceptance criteria.
- **Assessments:** structured evidence of mastery.

## Pedagogical principles

- State prerequisites and learning outcomes.
- Move from intuition to precise explanation and application.
- Mix retrieval practice with worked examples.
- Use feedback that explains reasoning, not only correctness.
- Avoid equating time spent or pages read with mastery.
- Provide accessible alternatives for visual or interactive activities.
