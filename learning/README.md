# Learning Academy

The learning layer turns reference knowledge into sequenced learning experiences. It is organised around a simple learner journey: choose a goal, learn the concepts, practise, build, and verify.

## Choose a learning experience

- **Build from Scratch:** learn by building small versions of real systems. Start at [the academy index](build-from-scratch/README.md).
- **Roadmaps:** prerequisite-aware journeys toward a defined capability.
- **Courses:** ordered groups of lessons.
- **Lessons:** focused instruction with measurable objectives.
- **Exercises:** practice tasks with hints and assessment criteria.
- **Quizzes:** checks for recall and conceptual understanding.
- **Projects:** applied work with requirements, milestones, and acceptance criteria.
- **Assessments:** structured evidence of mastery.

## Learning levels

- **Beginner:** first principles, vocabulary, guided examples.
- **Intermediate:** combine concepts, implement small systems, debug independently.
- **Advanced:** reason about trade-offs, performance, architecture, and correctness.
- **Specialist:** research literature, formal constraints, production-grade design, and independent evaluation.

A level label is guidance, not a guarantee that every learner has the same prerequisites.

## Pedagogical principles

- State prerequisites and measurable learning outcomes.
- Move from intuition to precise explanation and application.
- Mix retrieval practice with worked examples.
- Use feedback that explains reasoning, not only correctness.
- Avoid equating time spent or pages read with mastery.
- Provide accessible alternatives for visual or interactive activities.
- Label draft, reviewed, verified, and outdated material honestly.
