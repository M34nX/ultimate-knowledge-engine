# Learning Roadmaps

A roadmap is an ordered path through learning outcomes, not merely a list of popular tools.

Each roadmap should specify:
- intended learner and target capability;
- assumptions and starting level;
- ordered stages and prerequisite IDs;
- practical milestones and assessment evidence;
- optional branches and alternative technologies;
- realistic scope and maintenance notes.

Avoid promising mastery from a fixed number of days or hours.
