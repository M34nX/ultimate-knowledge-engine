# Guided Projects

Projects connect concepts into practical, reviewable work.

Every project brief should define:
- learner level and prerequisites;
- problem statement and scope;
- functional and non-functional requirements;
- milestones and deliverables;
- constraints and safe setup;
- acceptance criteria and evaluation rubric;
- extension ideas and further reading.

Prefer projects that can be completed locally with free tools and synthetic/sample data.
