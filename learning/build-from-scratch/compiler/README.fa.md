# ساخت یک زبان برنامه‌نویسی کوچک

**سطح:** متوسط تا پیشرفته · **زبان:** Python یا TypeScript · **وضعیت:** پیش‌نویس

## خروجی
یک زبان کوچک برای عبارت ریاضی، متغیر و پرانتز با پیام خطای روشن بسازید. ابتدا مفسر ایجاد کنید؛ بایت‌کد توسعه اختیاری است.

## پیش‌نیازها
تابع، بازگشت، رشته، درخت و ریاضیات گسسته مقدماتی.

## درس‌ها
۱. **طراحی زبان:** دستور زبان کوتاه و تقدم عملگرها را تعریف کنید.
۲. **واژه‌کاوی:** متن را به توکن همراه با موقعیت تبدیل کنید.
۳. **تجزیه:** از توکن‌ها درخت نحو انتزاعی (AST) بسازید.
۴. **ارزیابی:** درخت را با محیط نگهداری متغیرها اجرا کنید.
۵. **خطایابی:** نویسه نامعتبر، توکن غیرمنتظره و نام تعریف‌نشده را با محل خطا گزارش کنید.
۶. **توسعه:** تابع اضافه کنید یا AST را به بایت‌کد مستند تبدیل کنید.

## مراحل ساخت
- ۱: توکن‌ساز عبارت ریاضی
- ۲: تجزیه تقدم و پرانتز
- ۳: ارزیاب AST
- ۴: متغیر و انتساب
- ۵: پیام خطای مفید و آزمون خودکار
- ۶: ماشین مجازی بایت‌کد اختیاری

## تمرین
عبارت 2 + 3 * 4 را از توکن‌سازی تا ارزیابی دنبال کنید. توضیح دهید چرا تقدم عملگر با اجرای صرفاً چپ به راست یکسان نیست.

## معیار پذیرش
دستور زبان مستند باشد؛ آزمون‌ها تقدم و ورودی خراب را پوشش دهند؛ خطا محل مشخص داشته باشد؛ برای اجرای عبارت کاربر از تابع eval زبان میزبان استفاده نشود.
