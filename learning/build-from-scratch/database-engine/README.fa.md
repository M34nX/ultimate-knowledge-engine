# ساخت یک موتور پایگاه داده کوچک

**سطح:** متوسط · **زبان:** Python · **وضعیت:** پیش‌نویس

## خروجی
یک پایگاه داده آموزشی در حافظه با جدول، طرح داده، افزودن، خواندن، ویرایش، حذف، نمایه ساده و ذخیره‌سازی فایل بسازید. این پروژه جایگزین پایگاه داده واقعی نیست.

## پیش‌نیازها
تابع، کلاس یا رکورد، نگاشت، فهرست، ورودی/خروجی فایل و تحلیل مقدماتی الگوریتم.

## درس‌ها
۱. **مدل داده:** جدول را با طرح ستون‌ها و ردیف‌ها نمایش دهید و نام و نوع ستون‌ها را اعتبارسنجی کنید.
۲. **پرس‌وجو:** پیش از ساخت SQL کامل، چند دستور محدود پیاده کنید.
۳. **نمایه:** جست‌وجوی خطی را با جست‌وجوی هش مقایسه کنید.
۴. **تراکنش:** آغاز، ثبت نهایی و بازگشت تغییرات را با snapshot یا فهرست تغییرها مدل کنید.
۵. **ذخیره‌سازی:** داده را با قالب مستند ذخیره و هنگام بارگذاری اعتبارسنجی کنید.

## مراحل ساخت
- ۱: ساخت جدول و اعتبارسنجی طرح
- ۲: افزودن ردیف و رد داده نامعتبر
- ۳: انتخاب ردیف با شرط برابری
- ۴: ویرایش و حذف
- ۵: ساخت نمایه و سنجش کارایی
- ۶: ذخیره، بارگذاری و آزمون بازگشت

## تمرین
توضیح دهید چرا نمایه خواندن را سریع‌تر، اما مصرف حافظه و هزینه نوشتن را بیشتر می‌کند. برای کلید تکراری، ستون ناموجود، فایل خراب و جدول خالی آزمون طراحی کنید.

## معیار پذیرش
عملیات آزمون داشته باشند؛ ورودی نامعتبر ایمن رد شود؛ داده ذخیره‌شده بازیابی شود و محدودیت‌های بنچمارک ثبت شوند.
