# ساخت یک سرویس شبکه محلی

**سطح:** متوسط · **زبان:** Python یا JavaScript · **وضعیت:** پیش‌نویس

## خروجی
یک سرویس کوچک HTTP روی localhost بسازید که مسیرها، اعتبارسنجی ورودی، پاسخ ساخت‌یافته، آزمون و خاموش‌شدن کنترل‌شده داشته باشد.

## پیش‌نیازها
تابع، JSON، مفاهیم HTTP و خط فرمان.

## درس‌ها
۱. **کارخواه و کارساز:** درخواست، پاسخ، روش، مسیر، سرآیند و کد وضعیت را بشناسید.
۲. **مسیریابی:** مسیرها را به تابع‌های پاسخ‌گو متصل کنید.
۳. **اعتبارسنجی:** شکل داده ورودی را بررسی و داده نامعتبر را رد کنید.
۴. **خطا و گزارش:** خطای یکنواخت برگردانید و اطلاعات محرمانه یا جزئیات داخلی را افشا نکنید.
۵. **آزمون:** آزمون یکپارچه محلی بنویسید.
۶. **پایداری:** مهلت زمانی، محدودیت اندازه درخواست و خاموش‌شدن کنترل‌شده اضافه کنید.

## مراحل ساخت
- ۱: پاسخ سلامت روی localhost
- ۲: دو مسیر و خروجی JSON
- ۳: اعتبارسنجی و کد وضعیت مناسب
- ۴: آزمون حالت موفق و ناموفق
- ۵: مستندسازی پیکربندی و خاموش‌شدن ایمن

## مرز ایمنی
سرویس به‌طور پیش‌فرض فقط روی localhost گوش کند. سامانه‌ای را که مالک آن نیستید یا مجوز آزمونش را ندارید اسکن یا بررسی نکنید. اطلاعات ورود یا داده شخصی جمع‌آوری نکنید.
