## A simple path through every track

1. Check the prerequisites and learning outcomes.
2. Study the lessons in order and write down unfamiliar terms.
3. Complete milestones one at a time.
4. Solve the exercises without copying a finished solution.
5. Use the acceptance criteria to check your work.
6. Read the linked primary documentation for deeper study.

## Quality and safety

- Every track should state level, prerequisites, objectives, milestones, exercises, and acceptance criteria.
- Draft means the material has not yet passed the full editorial and technical review.
- External tutorials remain with their publishers; UKE links to them instead of copying them.
- Use public and appropriately licensed datasets and assets.
- Keep network exercises on localhost or an explicitly authorized lab.
- Keep operating-system experiments in user space or a disposable virtual machine.
- Do not run unreviewed code with elevated privileges or on a primary device.
