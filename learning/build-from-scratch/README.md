# Build from Scratch Academy

Learn how real technologies work by building small, understandable versions. This academy combines original UKE lessons with links to independent external tutorials.

## Tracks
- [Tiny AI model](ai-model/README.md) — data, training, loss, evaluation, and responsible use.
- [2D game](game-development/README.md) — game loop, input, state, movement, collision, and scoring.
- [Operating-system simulator](operating-systems/README.md) — processes, scheduling, virtual memory, and system calls.

## Study method
1. Read the concept lesson and identify unfamiliar terms.
2. Build each milestone in order.
3. Run the experiments and record results.
4. Solve exercises without copying a completed solution.
5. Check the acceptance criteria before extending the project.

## Source and safety policy
UKE lesson text and exercises are original unless attributed. External tutorials remain the property of their publishers; this project links to them rather than copying them. Verify availability, version, and licence before reuse. Keep OS experiments in user space or a disposable virtual machine; do not run experimental kernels on a primary device. Use public, appropriately licensed datasets and game assets.
